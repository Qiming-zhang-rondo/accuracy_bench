3对齐输入

L2 使用 L1 缓存做目标层反事实诊断。 每侧只使用一张设备卡；目标层可手动填写，也可留空后按 ref 模型、Prompt 和 cache 目录自动发现。Prompt 必须与生成缓存时完全一致。
推荐 AUTO：只量化 descriptor 明确声明了 activation quant 的 quant 侧算子；FLOAT、回退层和不匹配的量化类型不会被全局误量化。显式类型用于只验证指定激活格式。
这些层必须已有 L1 hidden-state cache；留空时自动发现当前模型与 Prompt 可用的缓存层。
L1 写入、L2 读取必须指向同一目录。
普通非旋转 W8A8 留空。若提供，ref 与 quant 必须使用同一旋转契约。
应填写部署时真实收到的输入；不要把模型已经生成的 Thinking Process 拼回来。
这不是 draft checkpoint 自带文件。它是 verifier/target 模型对一条真实输入执行 forward 时导出的中间激活，至少包含 input_ids、配置指定层的 hidden_states 和 loss_mask；Speculators 还需要 verifier_last_hidden_states。没有预先导出的 .pt 时，standalone DSpark L1 不能只靠 prompt 运行。

    Choose a Mode
    
          
    先回答你要定位哪一层问题
    
        
    
        
    大多数 ref/quant 数值排查从 L1 开始；只有已拿到部署坏输出时才先做 boundary。
    
      
    
      
    
        
    L0 · SCREENING
    文件先验检查
    不依赖 NPU，检查 config、权重索引、量化描述和文件完整性。
    
        
    L1 · DEFAULT
    找到误差突降层
    逐 decoder block 比较 hidden states，并缓存 Top-K 候选供 L2 使用。
    
        
    L2 · ROOT CAUSE
    验证根因子图
    复用 L1 cache，做反事实替换并输出 Recovery Ratio 与 RootSuspect。
    
        
    BOUNDARY
    区分框架与权重
    对照 Transformers 反量化基线和部署输出，判断坏输出来源。
    
      
    
    
    

    
    
      
    
        
    
          
    Runtime Boundaries
    
          
    三个不能混用的运行契约
    
        
    
        
    生成器会自动套用这些约束；手写命令时也应保持一致。
    
      
    
      
    
        
    普通 Dense
    使用 dual；ref/quant 各一个逻辑设备即可。大模型可通过 shard 控制峰值。
    
        
    MoE / Qwen3.6 / Kimi K3
    推荐 grouped_dual，分别提供 ref_devices 与 quant_devices。Kimi K3 官方 ModuleList 路径为必选。
    
        
    Standalone DSpark
    只支持专用 L1：dual + dequantize，必须提供 verifier hidden-state 样本；不能独立 generate。
    
      
    
    
    

    
    
      
    
        
    
          
    CLI Reference
    
          
    完整参数表
    
        
    
        
    参数名以 run_accuracy_check.py 为准。下表覆盖当前入口及历史兼容 alias。
    
      
    
      
    
        
        
      
    
      
    
        
    
          
    参数默认 / 取值说明与边界
    
          
            
    --model1（未传时）screening / boundary / l1 / l2 / full / report / inference。
    
            
    --result_json空report 从 ReportData JSON 重建 HTML；inference 也可读取推理结果 JSON。
    
            
    --ref_model空BF16/FP16 参考模型路径。L1 必需；boundary 中建议提供。
    
            
    --quant_model空量化模型路径。除 report / inference 特殊输入外通常必需。
    
            
    --l1 / --l2 / --all / --boundaryfalse历史兼容开关；新命令优先使用 --mode。
    
            
    --prompt内置中文短句对齐或生成输入。应使用真实 bad case 的原始输入。
    
            
    --messages空Chat messages JSON；会调用 tokenizer 的 apply_chat_template。
    
            
    --target_layers / --target-layers空L2 目标层，支持逗号或空格分隔。
    
            
    --devicecuda（自动解析）通用设备；NPU 建议显式指定 ref/quant 设备参数。
    
            
    --ref_device继承 devicedual / DSpark 的参考模型设备。
    
            
    --quant_device继承 devicedual / DSpark 的量化模型设备。
    
            
    --dtypebfloat16bfloat16 / float16；Ascend NPU 推荐 bfloat16。
    
            
    --clean_cachefalse清除 L2 cache 后退出。
    
            
    --cache_dir./.acc_cacheL1 写入、L2 读取的 cache 路径；也可用 ACC_CACHE_DIR 环境变量。
    
            
    --debugfalse输出 hidden norm、MoE L3 expert、设备与 NaN 等开发诊断；默认关闭以避免 NPU 同步和日志刷屏。
    
            
    --per_device_memory64 GB每卡显存预算。
    
            
    --quant_methoddequantizedequantize / fake_quant；standalone DSpark 只支持 dequantize。
    
            
    --layers_per_shard8L1 每批层数。4 卡大模型建议从 2 开始，显存充足再增大。
    
            
    --cache_top_k0保存 cos_sim 最低的 N 层输入供 L2 使用。
    
            
    --l1_target_layers空L1 只报告指定层，但仍从第 0 层 forward 以保持真实上下文。
    
            
    --rotation_matrix空QuaRot 等旋转量化且 R 未融合时提供；普通非旋转 W8A8 不需要。
    
            
    --mla_fine / --no_mla_fine开启控制 L2 MLA attention 的细粒度拆分。
    
            
    --activation_quantfalse仅在 L1 quant 侧启用 descriptor 驱动的激活伪量化；ref 始终保持原始精度。
    
            
    --activation_quant_typeAUTOAUTO 按每个权重的 descriptor 自动选择；也可显式指定 W8A8_MXFP8 / W4A8_MXFP / W4A4_MXFP4 / W4A4_DYNAMIC。
    
            
    --compare_modedualdual / grouped_dual；MoE 推荐 grouped_dual，DSpark 必须 dual。
    
            
    --ref_devices空grouped_dual 的 ref 多卡列表，例如 npu:0,1。
    
            
    --quant_devices空grouped_dual 的 quant 多卡列表，例如 npu:2,3。
    
            
    --expert_chunk_size按卡数自动grouped_dual 每批 expert 数；通常留空。
    
            
    --kimi_kda_backendautoauto / torch / chunk / fused_recurrent；auto 在 Ascend 上预装纯 torch import shim，无需 fla-core，并使用等价的 torch KDA recurrence。
    
            
    --output_dir自动单次报告目录；留空或填写 reports 时自动创建带时间戳目录。重复使用已有非空目录时自动创建同级归档，避免覆盖历史。
    
            
    --model_typeauto支持 dense、moe、GLM、Qwen3 系列、Qwen3.6、Kimi K3 与 dspark。
    
            
    --dspark_sample空（必需）DSpark verifier hidden-state .pt；包含 input_ids、hidden_states、loss_mask 等。
    
            
    --dspark_seed0DSpark anchor/noise 确定性采样 seed。
    
            
    --dspark_max_anchors8DSpark 单次诊断最大 anchor 数，工具会按样本和 config 自动下调。
    
            
    --devices空boundary 逻辑设备列表。
    
            
    --max_new_tokens1024boundary / full 最大生成 token 数。
    
            
    --thinkingchatboundary 思维链开关：chat / none。
    
            
    --framework_name空部署框架名，例如 vllm-ascend 或 MindIE。
    
            
    --framework_bad_output空部署框架实际生成的完整坏输出。
    
            
    --top_k1full 模式从 L1 选取进入 L2 的层数。
    
            
    --logitsfalsefull 模式额外收集 ref/quant logits。
    
            
    --manifest空bad case ground-truth manifest JSON。
    
            
    --quant_format空写入报告的量化格式标签。
    
            
    --model_name空写入 full / report overview 的模型名。
